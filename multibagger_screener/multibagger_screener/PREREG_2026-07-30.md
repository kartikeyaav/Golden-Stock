## Scoping measurements run BEFORE writing this file

Disclosed because they shaped the configs, and because both corrected a claim
made in conversation. Neither tests either hypothesis.

**A1 — the anticipation tier is not rare.** Live count: 11 names carry the
ANTICIPATION tag tonight, and `WATCH CLOSELY` has fired **80 times in 15 scan
days** (~5.3/day) — **30% of all 266 journalled alerts**, the third-largest
class. The premise "it fires rarely" was wrong. The question is therefore NOT
how to make it fire more; it is whether a fundamental filter makes a
already-high-volume, zero-capital stream selective enough to deserve capital.

**A2 — young listings are over-represented among top movers, but by ~2×, not
by the margin claimed.** Names under 260 bars are **36 of 651 = 5.5%** of the
universe. Their share of the top movers:

| window | top-20 young | top-50 young | lift vs 5.5% base |
|---|---|---|---|
| 1m | 10% | 8% | 1.8× |
| 3m | 15% | 8% | 2.7× |
| 6m | 10% | 14% | 1.8× |

The 3-month top-12 contains exactly **one** young name (STYL). The claim that
"this is where the 10x names you are missing actually are" was extrapolated
from a single week's capture audit in which 2 of the top 3 movers happened to
be TOO YOUNG, and that was small-sample noise. The real effect is a ~2× lift on
a 5.5% base — enough to justify building A2, not enough to justify prioritising
it above A1. Priority order in this document reflects the correction.

## A1 — anticipation tier with fundamentals as the primary pre-breakout signal

### Hypothesis

V3a is the only fundamental configuration ever to pass a pre-registered bar in
this project: anticipation entries filtered by PIT fundamentals ≥0.60 returned
**+0.41R, positive in both cohorts (+0.82 / +0.06)**, against **+0.06R** for the
same tier price-only (P2 negative). VALIDATION_REPORT records the mechanism as
*"fundamentals LEAD price inside bases — the mirror image of the entry-gate
rejection."* The tier was left at **zero capital** because +0.41R is far below
breakout economics, and that disposition has never been revisited.

Claim under test: a fundamentally-filtered anticipation sleeve is **additive at
the portfolio level** even though its per-trade expectancy is inferior, because
it deploys capital into names during quiet basing periods when the breakout
queue is not filling slots.

### Why this could fail, stated in advance

Utilisation was previously measured at ~73% deployed with the 12-slot cap
binding on 39% of days. If anticipation entries mostly compete for slots that
breakouts would have taken, the sleeve **cannibalises a +1.67R entry to fund a
+0.41R one** and must be rejected regardless of its standalone number. The
configs below are built to detect exactly that.

### Configs

All use a SEPARATE risk budget so the sleeve cannot starve the breakout queue.

| id | description |
|---|---|
| `A1_control` | canonical baseline, no anticipation capital (reproduction check) |
| `A1_a` | anticipation sleeve, PIT fundamentals ≥0.60, risk 0.625% (half), max 4 concurrent, slots ADDITIONAL to the 12 |
| `A1_b` | as `A1_a` but sharing the existing 12 slots (the cannibalisation case) |
| `A1_c` | as `A1_a` at full 1.25% risk |
| `A1_d` | as `A1_a` with fundamentals ≥0.70 (tighter, fewer names) |

Exits for anticipation lots follow the existing two-lot rules unchanged. V3a
already measured the core lot as structurally capped near a flat 30-week MA
(+0.26R); no exit rule is modified here.

### Decision rule — fixed

A1 is **ADOPTED** only if `A1_a` (the pre-specified primary config) satisfies
**all four**:

1. Combined portfolio **MAR ≥ 3.58** (the current breakout+EP figure). Equal is
   not enough on its own but is permitted if (4) improves.
2. Max drawdown **no worse than −20.7%** (the stressed deployment number).
3. **P2 chop cohort ≥ 0** for the combined portfolio.
4. Combined CAGR **≥ baseline**, i.e. the sleeve does not dilute returns.

`A1_b` is diagnostic only: if `A1_b` is materially worse than `A1_a`, that
confirms cannibalisation and **no shared-slot variant may ever be adopted**.
`A1_c` and `A1_d` are dose-response probes — if results are non-monotonic across
risk (a/c) or threshold (a/d), the effect is noise and A1 is REJECTED whatever
`A1_a` alone shows. This clause exists because dose-response is what exposed
every previously rejected overlay.

Failing any of 1–4: anticipation stays **zero capital, alerts only**, and this
document records the second rejection of the tier for capital purposes.

## A2 — IPO-base module for names under 260 bars

### Hypothesis

The trend template needs ~45 weeks of structure, so names under 260 bars can
never qualify; the only path open to them is the EPISODIC PIVOT class. This is
the measured IREDA / WAAREERTL blind spot. Young listings are ~2× over-
represented among top movers (scoping table above), so a shorter-lookback base
definition should recover entries the current system cannot see.

### Configs

Historical young cohort is built per name from its own listing date, so a name
mature today is treated as young during its first year — no look-ahead.

| id | description |
|---|---|
| `A2_control` | canonical baseline (young names excluded, as today) |
| `A2_a` | IPO base: min 60 bars, 10-week base window, ≥3 contractions relaxed to ≥2, breakout ≥1.5× vol (same as VCP) |
| `A2_b` | as `A2_a` with min 90 bars |
| `A2_c` | as `A2_a` but requiring the gap-day/EP volume standard (≥3× vol) |

Stop: existing ATR rule with the existing 12% cap. **The cap will exclude many
young names by design** — that is a known, accepted consequence, not a bug to
engineer around, and the count of names skipped for stop width will be reported.

### Decision rule — fixed

A2 is **ADOPTED** only if `A2_a` satisfies **all three**, mirroring the bar the
EPISODIC PIVOT class had to clear:

1. Standalone expectancy **≥ +0.75R** (EP cleared +1.38R; a class carrying
   capital must be meaningfully profitable on its own, not merely positive).
2. **P2 cohort ≥ 0** — no class is adopted that only works in the bull cohort.
3. Combined portfolio **MAR ≥ 3.58** and max DD no worse than **−20.7%**.

Additional kill condition: if fewer than **25 entries** fire across the whole
window, the sample cannot support adoption at any expectancy and A2 is
**MEASURED BUT NOT ADOPTED** — recorded, revisited when the sample grows. This
threshold is set now, before the entry count is known.

## Discipline notes binding both

- Per-config trade files saved to `matrix_trades/` (A1_*.csv, A2_*.csv) so
  trade-level diffs are possible, per the matrix-v2 lesson.
- Neither test may modify the breakout entry, the conviction score, the vetoes,
  or any existing threshold. If a config requires such a change to pass, it
  fails instead.
- Survivorship: the universe is index-constituent based and survivor-biased
  (measured ~9.2% churn / 2y). A favourably-biased backtest that a config still
  fails kills it; passing is necessary, not sufficient.
- Results — including rejections — are written into `VALIDATION_REPORT.md` and
  an OUTCOME block is added to the top of this file, whichever way they land.
